Enable CUDA graphs for hybrid chunked prefill and Mamba intermediate-state extraction

Megatron-LMCUDA graphsInference engine

Make Mamba prefix caching CUDA-graph compatible on hybrid (transformer + Mamba) models during inference, and then delete the three eager-mode escape hatches that existed only because it was not. Today, any dynamic-inference batch that has to extract intermediate Mamba state — and, separately, any hybrid batch at all when chunked prefill is enabled — is forced to run eagerly. That is because the extraction path is written in data-dependent Python: variable-length lists of per-request offsets, a per-request `causal_conv1d` loop with `.item()` calls in it, and per-layer intermediate states buffered into a Python dict and assembled after the fact. None of that can be captured or replayed inside a CUDA graph. This change turns the extraction into a fixed-shape, vectorized write into pre-allocated per-layer output buffers, so those batches replay a graph and still commit exactly the state a full recomputation would have produced.
