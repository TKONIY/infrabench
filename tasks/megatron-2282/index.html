Hybrid context parallelism

Megatron-LMParallelism

Today context parallelism has exactly one degree: a job picks `cp_size` once, and every sample is split across that many ranks. This change adds hybrid context parallelism: the DP×CP world is additionally carved into sub-groups of several different sizes, and a sample can then be given exactly as many ranks as its own sequence length needs — a short sample runs on one rank, a long one is spread over several. The plumbing that follows from that is the rest of the change: a scheduler that decides which sample goes to which sub-group, a data-loader path that redistributes samples accordingly, a forward/backward schedule that copes with a CP degree that varies per micro-batch, and the attention/rotary changes that make a variable degree work.
