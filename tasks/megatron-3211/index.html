Add multi-module heterogeneous parallelism support for MIMO model

Megatron-LMParallelism

Let a MIMO (multi-input/multi-output) model spread its modules across disjoint sets of ranks with independent parallelism, instead of requiring every rank to hold every module under one shared parallel configuration. A user supplies a map from module name to communication grid; from it, each rank derives its own role — which modules it participates in, and whether it is the first and/or the last pipeline stage of each — and then builds and runs only what that role assigns it.
