DeepSeek V3.2 support

Megatron-LMModel supportAttention

Add DeepSeek-V3.2-style sparse attention (DSA) to Megatron-Core, as an opt-in attention variant layered on top of Multi-Latent Attention. Instead of every query attending to its whole causal prefix, a small learned indexer module scores the keys for each query, and attention is computed over only the top-k keys the indexer picked for that query, intersected with what causality allows. The indexer is trained by an auxiliary divergence loss against the true attention distribution, carried back through the graph independently of the main loss.
