Add absorbed-mla

Megatron-LMAttention

Add a new experimental attention variant, `AbsorbedMLASelfAttention`, that is a mathematically exact alternative to the existing `MLASelfAttention`. Standard MLA compresses K and V into a shared low-rank latent, then up-projects that latent back into `n` per-head keys and values before running core attention. The absorbed variant keeps the up-projections out of the K/V path entirely: core attention runs in MQA form over a single-head latent KV, and the value up-projection is applied to core attention's output instead. Outputs and gradients must be numerically indistinguishable from standard MLA, and a checkpoint trained with standard MLA must load into it.
