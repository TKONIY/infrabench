Prefix caching for dynamic-batching inference

Megatron-LMInference engineKV cache

Teach Megatron's dynamic-batching inference path to reuse KV cache that has already been computed. Today every request prefills its whole prompt, even when another request in the same engine has an identical prompt prefix and its KV blocks are sitting right there in the pool. This change makes a request discover those blocks, adopt them by reference instead of allocating and recomputing, and prefill only the tail of its prompt that nobody has computed yet.
