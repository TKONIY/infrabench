verlRL trainingDiffusion

Make the FlowGRPO diffusion RL trainer runnable end to end. The repository already has a diffusion rollout path, a diffusers training engine and a diffusion policy loss, but nothing that drives them: there is no diffusion advantage estimator, no diffusion metric reporting, no diffusion trainer loop and no entrypoint. This change adds all four, moves the diffusion-specific algorithm helpers into a diffusion package of their own, and adds the configuration that selects them.
