Dynamic inference: suspend and resume the engine

Megatron-LMInference engine

Make an in-flight dynamic-inference request survive a teardown of the engine's GPU state. Today a request is a single mutable object that lives for exactly one run: if the engine gives its memory back, the request is gone. This change turns it into a record — the history of the successive attempts one request passed through. The engine gains a suspend operation that hands essentially all of its device memory back and parks every request it was serving, and a resume operation that rebuilds that state and puts those requests back into flight so they run to completion. When a request finally finishes, its record is merged back into a single, suspend-agnostic request that looks exactly like the output of an uninterrupted run.
