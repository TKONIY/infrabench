feat(moe): Fine-grained activation offloading

Megatron-LMMemory

Add fine-grained activation offloading. During the forward pass, the input activations of a user-chosen set of transformer sub-modules are copied out of GPU memory into pinned host memory and their device storage is released; before the matching backward pass runs, they are copied back. The user picks which sub-modules participate — attention norm, QKV linear, core attention, attention projection, MLP norm, expert FC1, MoE activation — so the amount of offloaded memory can be dialled to whatever the host↔device bandwidth can hide.
