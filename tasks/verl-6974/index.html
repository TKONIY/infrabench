[ckpt,rollout] feat: sharded delta weight sync over NCCL for disaggregated rollout

verlWeight sync

Add `delta_sharded`, a sparse weight-sync checkpoint-engine backend for disaggregated (separate trainer / rollout) async training. Instead of broadcasting every parameter byte on every sync, each actor rank compares **its own local parameter shard** against a pinned CPU snapshot of that same shard, only the changed `(position, value)` pairs are gathered to the root of the shard's own process group and broadcast over the existing collective group, and the rollout side applies them **in place** through the inference engine's stock custom-weight-loader hook.
